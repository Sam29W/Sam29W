### 01 — YOLO Object Detection Pro

A computer-vision project exploring object detection, multiple YOLO model variants, and image/video processing workflows.

- Object detection and model integration.
- Webcam and video-analysis workflows.
- Detection configuration and alert-oriented features.

**Focus:** Python · YOLO · Computer Vision

[VIEW SOURCE CODE →](https://github.com/Sam29W/YOLO-Models)

### 02 — Sally5 / CheckoutKit

A checkout-platform project designed around the needs of Indian direct-to-consumer merchants.

- Checkout flows and phone-OTP authentication.
- Address management and payment orchestration.
- COD-risk scoring and merchant dashboard capabilities.

**Architecture:** NestJS · SvelteKit · PostgreSQL · Redis · Redpanda

[VIEW SOURCE CODE →](https://github.com/Sam29W/Sally5)
